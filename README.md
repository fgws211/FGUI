FairyGUI（FGUI）是 Unity 游戏开发中常用的 UI 框架，但原生 API 的使用流程繁琐——加载包、创建界面、挂载渲染、查找控件、绑定事件，每一步都要手动写，重复代码多且容易出错。

目前本人最近在学习使用 FGUI，一个开源、免费的UI工具，因为要考虑团队合作（为了让我的同事不需要去看FGUI相关的接口文件 PS:偷懒），所以考虑对 FGUI 原生库再套一层封装。给大家分享，有什么修改上面的意见可以留言，本人看到了会尽快修改。

本文分享一个自研的开源、免费的 FGUI 轻量封装库，把整个流程压缩成三个核心方法：Awake() 自动扫描加载所有 UI 包、OpenFGUI() 打开界面、BindButton() 绑定按钮事件，并内置预创建缓存机制，让界面“秒开”不卡顿。
